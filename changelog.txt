Knight Armor and Weapons Changelog
==================================

1.1.2-Fabric-mc1.21.1
---------------------
Fixes
 - Crash at startup on Minecraft 1.21.2 and newer: the mod now only loads on Minecraft 1.21 and 1.21.1, other versions show a clear message instead
Changes
 - Now also works on Minecraft 1.21
1.1.1-Fabric-mc1.21.1
---------------------
New
 - First release for Fabric 1.21.1, with the same content and behavior as the other versions: Knight armor with its own 3D model, Knight Longsword, Spiked Mace, Hand Scythe and throwing axe. Requires Fabric API
1.1.0-Fabric-mc1.20.1
---------------------
New
 - First release for Fabric, with the same content and behavior as the Forge version 1.1.0: Knight armor with its own 3D model, Knight Longsword, Spiked Mace, Hand Scythe and throwing axe. Requires Fabric API
